Panel Press — an offline browser web app that turns a photo and a caption into GTA 6-style cover art: multi-panel poster layouts, Vice City neon-sunset grades, and PNG export in three post sizes. Entry for the make.fun competition gta6-cover-art-01.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
